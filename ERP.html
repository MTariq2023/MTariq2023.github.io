ERP Business Analytics Demo

Integrating Odoo ERP with PostgreSQL and Power BI

Project Overview

This project demonstrates an ERP data pipeline using Odoo ERP as the source system, PostgreSQL for structured data storage, and Power BI for reporting. It simulates a real-world Applications Analyst workflow, including ERP transactions, SQL queries, and BI dashboards.

Key Features

  • Configured Odoo ERP modules for Sales, Purchases, and Inventory management.
  • Captured transactions (orders, vendors, products, employees) in ERP.
  • Connected Odoo’s PostgreSQL backend directly in Power BI.
  • Created DAX measures for Sales, Purchases, and Profit.
  • Designed an interactive dashboard with KPIs, cards, and trend charts.
  • Performed a sample ERP security audit (user roles, permissions, and database access).

Technology Stack

  • ERP System: Odoo 16 (Docker)
  • Database: PostgreSQL
  • Visualization: Power BI
  • SQL Tools: pgAdmin, DBeaver
  • Languages: SQL, DAX
