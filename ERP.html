ERP Sales & Inventory Dashboard

Project Overview

This project demonstrates how ERP system data (Odoo) can be connected to a PostgreSQL database and visualized in Power BI. The dashboard provides insights into total sales, purchases, inventory stock, and profit trends, helping businesses make data-driven decisions.

Tools & Technologies

  • Odoo ERP (data export)
  • PostgreSQL (database backend)
  • SQL (data queries & cleaning)
  • Power BI (data visualization)

Dashboard Preview

Key Features

  • Total Sales and Purchases KPIs
  • Stock versus Reserved Inventory Analysis
  • Sales, Purchases, and Profit Trend Over Time
  • Data pipeline from ERP → SQL → Power BI
